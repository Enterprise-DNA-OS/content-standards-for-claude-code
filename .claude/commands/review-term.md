Read CLAUDE.md. Read the term first. Status is preferred, deprecated or proposed. Optional --replacement and --owner. Local review prevents conflicting source updates.

```bash
npm run standards -- review-term "<term code>" --status=preferred --review-due=YYYY-MM-DD --actor="<reviewer>"
```

Use --json for structured output. Replace placeholders with facts supplied by the operator. Read before writing. Ambiguous names list candidates and exit 1. Present blockers with their owner. Never send or publish.
