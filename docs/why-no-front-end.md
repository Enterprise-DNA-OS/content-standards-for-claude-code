# The review record is the product

An editor can operate this desk by asking for a review queue, checking a document, recording evidence and preparing a sign-off. The database holds the exact text, standards and decisions. Read-only HTML shows the week and the paperwork.

A screen provides inline highlights, collaborative editing, mobile capture, offline work and visual diffing. This base does not provide those experiences. It accepts plain text and Markdown, uses a literal phrase checker and relies on a human to assess claims and context. It has no browser extension, grammar engine, web crawler or publishing connection.

Enterprise DNA can build the editor connections, access controls and interface around the business’s version. The base is useful now for a trusted content desk that owns its source text and review process.
